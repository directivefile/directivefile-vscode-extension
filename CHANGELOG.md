# Changelog

## v0.0.8 - 2026-11-21

The First Public Version.

- **Syntax highlighting**: Highlights directives, parameters, comments, blocks, continuations, and environment placeholders.
- **Syntax error diagnostics**: Reports lexer errors and invalid directive structure in the Problems panel.
- **Formatting**: Formats directives, parameter alignment, nested blocks, continuation lines, comments, and blank lines.
